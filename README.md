# 🍂 Vintage Cologne

### A Modern Luxury Cologne Website

Vintage Cologne is a responsive and elegant e-commerce-style website concept designed for a premium men's fragrance brand. The website combines a sophisticated dark aesthetic with gold accents, luxury typography, and smooth interactive elements to create a refined digital experience.

---

## ✨ Project Overview

Vintage Cologne was created as a front-end web development project to demonstrate practical skills in **HTML, CSS, and JavaScript**.

The website presents a fictional luxury fragrance brand and includes product showcases, customer testimonials, a gallery, brand information, and a contact section.

The design focuses on creating a premium masculine identity through:

* 🖤 Dark luxury backgrounds
* 🥇 Gold accent colours
* 🍂 Elegant vintage-inspired branding
* 📱 Responsive layouts
* ✨ Interactive navigation
* 🖼️ High-quality visual presentation
* 💻 Clean and structured front-end code

---

## 🚀 Features

### 🏠 Home Section

A visually striking landing section introducing the Vintage Cologne brand with a premium luxury aesthetic.

### 📖 About Section

Provides information about the brand and its approach to sophisticated men's fragrances.

### 🧴 Premium Collection

Showcases the fictional Vintage Cologne collection, including:

* **Imperial Noir**
* **Royal Oud**
* **Midnight Legacy**
* **Executive Elite**
* **Golden Reserve**
* **Vintage Signature**

### ⭐ Testimonials

A customer testimonial section designed to showcase user experiences and provide social proof.

### 🖼️ Gallery

A visual section displaying luxury fragrance imagery and supporting the overall brand identity.

### 📞 Contact Section

Provides users with a way to interact with the fictional brand and access relevant contact information.

### 📱 Responsive Navigation

The website includes a mobile-friendly navigation menu that adapts to different screen sizes.

### 🎞️ Interactive Elements

JavaScript is used to provide interactive functionality such as navigation controls and dynamic components.

### 🔄 Swiper Integration

Swiper is used for interactive testimonial/content sliders, providing a smooth and modern browsing experience.

```bash

```

Navigate into the project directory:

```bash

```

Open `index.html` directly in your browser, or use **Live Server** in Visual Studio Code.
